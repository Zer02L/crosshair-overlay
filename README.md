# Crosshair Overlay (Rust)

Сверхлегковесный, высокопроизводительный кроссплатформенный оверлей прицела — аналог **Crosshair X**.

## 🚀 Ключевые особенности
* **Нулевой инпут-лаг и 0% CPU:** окно оверлея центрировано (128x128 пикселей), рендерится через аппаратно-ускоренный субпиксельный векторизатор `tiny-skia` и `softbuffer`.
* **Сквозные клики (Click-through):** функция `set_cursor_hittest(false)` позволяет кликам мыши проходить сквозь прицел прямо в игру без перехвата фокуса.
* **Безопасно для античитов:** никакой инъекции DLL в память игр (Vanguard, EAC, BattlEye, VAC не детектят).
* **Кроссплатформенность:** работает на Windows, Linux и macOS.
* **Архитектурный анализ:** подробное сравнение текущей монолитной схемы и перехода на Daemon + IPC доступно в [документации проекта](docs/architecture-comparison.md).

## ⚡ Примененные оптимизации разработки

В проекте уже настроены параметры для молниеносной разработки:
1. **Быстрый линкер LLD (`.cargo/config.toml`):**
   * Инкрементальная пересборка занимает **всего ~0.10 секунды**!
2. **Оптимизированный профиль dev (`Cargo.toml`):**
   * `debug = 1`: облегченные отладочные символы (папка `target/` не раздувается на десятки гигабайт).
   * `opt-level = 3` для внешних зависимостей: библиотеки `winit`, `tiny-skia` собираются оптимизированными один раз и работают с максимальной скоростью.
3. **Настройки VS Code (`.vscode/settings.json`):**
   * `rust-analyzer.numThreads: 2`: процессор не нагружается на 100% при проверке кода.
   * `checkOnSave.command: "check"`: проверка на лету за доли секунды.

## ⚙ Конфигурация прицела (`crosshair_config.json`)

При первом запуске создается конфигурационный файл `crosshair_config.json`:
```json
{
  "window_size": 128,
  "line_length": 10.0,
  "line_thickness": 2.0,
  "gap": 5.0,
  "center_dot": false,
  "center_dot_radius": 1.5,
  "t_style": false,
  "outline_enabled": true,
  "outline_thickness": 1.0,
  "outline_color": { "r": 0, "g": 0, "b": 0, "a": 220 },
  "color": { "r": 0, "g": 255, "b": 100, "a": 255 }
}
```
* `line_length` — длина перекрестия
* `line_thickness` — толщина линий
* `gap` — отступ от центра (зазор)
* `center_dot` — точка в центре
* `t_style` — T-образный прицел (без верхней риски)
* `outline_enabled` — контрастный черный контур вокруг линий
* `color` — цвет прицела (по умолчанию киберспортивный неоновый зеленый)

## 🗺️ Планы развития (Roadmap)

1. **Горячие клавиши (Hotkeys)**:
   * Возможность скрывать/показывать прицел по нажатию клавиши (например, `F10` или `Ctrl + Shift + X`).
   * В Wayland: реализация через глобальные шорткаты (`org.freedesktop.portal.GlobalShortcuts`) или отслеживание устройства ввода (`evdev`).

2. **Смена пресетов на лету (Live Reload)**: ✅ *Реализовано!*
   * Чтение и отслеживание `crosshair_config.json` в реальном времени при сохранении файла (через `notify` и событие в event-loop'е).
   * Прицел мгновенно меняет цвет, размер, толщину, обводку и стиль прямо во время игры без перезапуска приложения.

3. **GUI-настройщик / Tray Icon**:
   * Иконка в системном трее рядом с часами.
   * Контекстное меню по правому клику: выбор цвета, толщины, зазора или пресетов (круг, точка, перекрестие, динамический прицел).

4. **Кроссплатформенный релиз**:
   * Добавить сборку под Windows (`.exe`) в существующий GitHub Actions workflow, чтобы оверлеем можно было делиться и запускать на любой ОС.
